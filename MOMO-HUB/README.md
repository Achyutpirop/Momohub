## 🚀 Getting Started on Your PC

1. Ensure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).
2. Open your terminal inside this `MOMO-HUB` folder.
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open your browser at:
   ```text
   http://localhost:3000
   ```

## 🛠️ Project Structure

- `src/components/`: Modular React components (Navbar, Hero, Menu, SignatureDish, WhyUs, About, Gallery, Reviews, Location, OrderSection, Footer, MobileQuickBar, OrderDrawer, ScrollReveal)
- `src/data/restaurantData.ts`: Centralized menu items, prices in Nepali Rupees (Rs), contact numbers, opening hours, and reviews
- `src/assets/images/`: High-resolution culinary photos of The Momo Hub
- `src/index.css`: Tailwind styling, typography, and custom steam animations
